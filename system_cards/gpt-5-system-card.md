# GPT-5 Technical Report & System Card

Released in October 2025, GPT-5 is OpenAI's next-generation multimodal agentic model.

## Technical Specifications
* **Developer:** OpenAI
* **Architecture:** Multimodal MoE with background test-time reasoning
* **Context Length:** 500,000 tokens
* **Modalities:** Native Multimodal (Text, Vision, Audio)
